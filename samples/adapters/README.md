# Adapter samples

Four rail sections that hold in the grooves on slide keys: Picatinny, Weaver, NATO accessory rail and an Arca-Swiss style dovetail. The profiles are approximations from public descriptions, drawn from scratch, and are not verified against the standards or a real part. The target projects do not endorse MAV Grid (rule A-4).
