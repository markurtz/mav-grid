# Plate samples

One loose plate per plate kind that the toolkit models, at the smallest span the kind registry allows (rules P-1 and P-2). `mav-grid spec kinds` lists the kinds.

Plates that carry another system state their target (rules A-2 to A-4). Every pattern is modelled from scratch from published or surveyed dimensions, and none has been checked against a real part. Where a target's licence was not looked up, the record says so: read the target's terms before publishing a plate.

The `opengrid` and `multiboard` kinds have no sample, because the toolkit draws them plain until their licence terms are settled (test T-15).
