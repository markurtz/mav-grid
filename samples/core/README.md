# Core samples

Flat panels with one face, one per build mode of section 6 of the spec.

| Sample                                  | Shows                                                                             |
| :-------------------------------------- | :-------------------------------------------------------------------------------- |
| `panel-routed-large-6x4.json`           | Routed integral, Large: grooves cut into solid stock, 2 x 2 plates left standing. |
| `panel-swap-small-4x2.json`             | Swap base, Small: a core with core holes and eight loose plates.                  |
| `panel-swap-large-6x2-wide-plates.json` | Swap base, Large, with 3 x 1 plates and their fixing cells (rule P-13).           |
| `panel-cut-down-small-4x4.json`         | Cut-down sites (rule M-3).                                                        |
| `panel-surface-plates-small-4x3.json`   | Plates fixed to an existing surface, which is shown for context only.             |
