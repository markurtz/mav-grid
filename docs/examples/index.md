# Examples

Runnable examples of the MAV Grid toolkit. Each example lives in the [`examples/`](https://github.com/markurtz/mav-grid/tree/main/examples) directory with its own README and test.

> [!NOTE]
> All examples assume you have completed [Installation](../getting-started/installation.md).

| Example        | What it shows                                                      |
| :------------- | :----------------------------------------------------------------- |
| `project_info` | Print the toolkit version, the targeted spec version and settings. |

More examples arrive with the schema and generators: validating a sample parameter file, generating a grooved panel in both sizes, generating a face plate of any span, and building an adapter plate.
